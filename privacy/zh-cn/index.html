网站运行与联系

GitHub Pages 托管网站，并可能出于安全目的记录 IP 地址。现有 Google Fonts 请求用于提供字体，并向 Google 传送 IP 地址等连接技术信息。如您发送电子邮件，我们使用您的地址与内容回复，并在必要期间保存通信。这些处理用于网站运行、安全及回复咨询（合法利益或适用的订立合同前措施）。

可选访问统计

仅在同意后，Google Analytics 4（Google Ireland Limited／Google 集团）接收假名化 Cookie 标识、页面 URL、访问来源、大致国家、设备／浏览器信息及页面浏览、滚动、外部点击、下载和兼容视频事件等互动信息。我们基于同意进行网站统计与改进。未启用 Google Signals、User-ID 或广告个性化，也不在 Analytics 中索取姓名或电子邮件。拒绝不限制访问。个人级事件与用户数据按 Analytics 的有限保留设置保存（若用户数据无法选择更短期限，最长14个月）；汇总报告可能保留更久。隐私政策页面不安装 Analytics。

Cookie 与选择

第一方 Cookie _ga 和 _ga_X1LNTFZR2N 用于区分浏览器和会话。网站请求60天有效期，不随每次访问续期。必要的 localStorage 键 pe_web_privacy_v1 保存选择及日期180天。接受前不加载 Analytics 脚本或 Cookie。您可在页脚的 Cookie 设置中接受、拒绝或撤回。撤回会阻止之后的统计，删除可访问的 Analytics Cookie，并可能重新加载页面；不会追溯删除已发送的数据。您也可以在浏览器中清除网站数据。

外部视频与链接

嵌入的 YouTube 视频仅在单独确认后加载。Google/YouTube 会收到连接及播放数据，并可能使用 Cookie 或类似技术用于自身目的（包括广告）。停止外部视频会移除播放器；您也可以在浏览器中清除第三方网站数据。外部链接遵循相应服务的政策。Analytics 与 YouTube 的同意互相独立。

接收方、跨境传输及权利

服务商包括 GitHub 和 Google。数据可能在欧洲经济区之外（包括美国）处理；服务商在隐私通知中说明适用保障，如充分性决定或标准合同条款。在适用情况下，您可要求访问、更正、删除、限制、可携带、提出异议或撤回同意（不影响此前合法处理）。请联系上述责任方，或向西班牙数据保护机构 AEPD 投诉。
