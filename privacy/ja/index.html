ウェブサイトのプライバシーと Cookie

2026-11-28

管理者と適用範囲

PE Studio — Diego Ceballos、スペイン。連絡先：diego.ceballos.dev@pestudio.eu。本通知は pestudio.eu に適用されます。Sheep or Lead アプリ内の処理には別のポリシーがあります。

サイト運営とお問い合わせ

GitHub Pages がサイトをホストし、セキュリティのため IP アドレスを記録する場合があります。既存の Google Fonts への通信はフォントを取得し、IP アドレスなどの接続情報を Google に送ります。メールでのお問い合わせには、アドレスと本文を返信に利用し、必要な期間保存します。これらの目的はサイト運営、安全性、問い合わせへの対応です（正当な利益または該当する場合の契約前措置）。

任意のアクセス解析

同意した場合のみ Google Analytics 4（Google Ireland Limited／Google グループ）が、仮名化 Cookie 識別子、ページ URL、流入元、おおよその国、端末・ブラウザ情報、閲覧、スクロール、外部リンクのクリック、ダウンロード、対応する動画イベントを受信します。同意に基づきサイトの測定と改善に使用します。Google Signals、User-ID、広告パーソナライズは有効にせず、Analytics で氏名やメールを要求しません。拒否してもアクセスできます。個別データは Analytics の設定期間（短いユーザーデータ期間を選べない場合は最大14か月）保存され、集計レポートはさらに長く保存される場合があります。プライバシーポリシーのページでは Analytics は使用しません。

Cookie と選択

ファーストパーティ Cookie _ga と _ga_X1LNTFZR2N はブラウザとセッションを区別します。サイトは訪問ごとの更新なしで60日の有効期間を要求します。設定を記憶するため必要な localStorage キー pe_web_privacy_v1 は選択と日時を180日間保存します。同意前に Analytics のスクリプトや Cookie を読み込みません。フッターの Cookie 設定から許可・拒否・撤回できます。撤回は以後の解析を停止し、アクセス可能な Analytics Cookie を削除し、ページを再読み込みする場合があります。既に送信したデータを遡って削除するものではありません。ブラウザでサイトデータを消去することもできます。

外部動画とリンク

埋め込み YouTube 動画は別の確認後にのみ読み込まれます。Google/YouTube は接続・再生データを受信し、広告など独自の目的に Cookie や類似技術を使う場合があります。外部動画を停止するとプレーヤーが削除されます。ブラウザで第三者のサイトデータも消去できます。外部リンクには各サービスのポリシーが適用されます。Analytics と YouTube の同意は別々です。

提供先、移転、権利

提供事業者には GitHub と Google が含まれます。米国など EEA 外で処理される場合があり、事業者は十分性認定や標準契約条項などの保護措置を各通知に記載しています。適用される場合、アクセス、訂正、削除、制限、ポータビリティ、異議申立てを求め、以前の適法な処理に影響を与えず同意を撤回できます。上記管理者またはスペインのデータ保護機関 AEPD に連絡できます。
